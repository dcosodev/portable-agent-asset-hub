# Code of Conduct

## Our standard

We want this project to be a respectful, technically rigorous and welcoming space for contributors. Participants are expected to communicate professionally, assume good faith, and focus criticism on ideas, code and evidence rather than people.

Unacceptable behavior includes harassment, discrimination, intimidation, personal attacks, doxxing, sexualized attention, deliberate disruption, and publishing private information without consent.

## Enforcement

Project maintainers may remove or edit comments, close issues, reject contributions, or restrict participation when behavior violates this code. Reports should be made privately to the maintainer through the contact mechanism configured in the repository. Do not include secrets or private runtime data in a report.

This code applies in project spaces and whenever someone is representing the project publicly.
